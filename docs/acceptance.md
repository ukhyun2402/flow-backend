# 현재 수용 기준 · Python 0.2

원본 기획서와 사용자 추가 요청을 함께 추적한다. 실 DB 미검증 상태를 지원 완료로 표시하지 않는다.

| 기준 | 현재 상태 |
|---|---|
| Python 재구축 | FastAPI 관리 API·검증기·공통 엔진·독립 서버 생성 구현 |
| draw.io 교체 | 로컬 공식 배포본, 실제 iframe 초기화·XML 동기화·타입 메타데이터·그림 가져오기 구현. React Flow 제거 |
| Postman 스타일 UI | 컬렉션 트리·프로세스 탭·메서드/경로·Send·Params/Body/Auth/SQL·응답/Trace/Validation 구현 및 브라우저 검증 |
| 다중 DB 계층 | DB 필터 → 프로젝트 → 업무 → 프로세스 ID. 프로젝트 다중 DB 연결·SQL 노드별 DB 선택 구현 및 테스트 |
| AC-001 | 편집·저장·복원·실행 구현. 사용자 조회 Flow 제공. SQL 부분은 SQLite 브리지로 검사, vendor DB 수용 테스트 대기 |
| AC-002 | 위치·그림 XML은 실행 의미와 생성 산출물에서 분리, ZIP 동일성 테스트 |
| AC-003 | 노드별 도형·아이콘·이름 구현. draw.io 자체 노드 표현은 별도 XML 어댑터로 관리 |
| AC-004 | 실제 Tibero·Oracle·MySQL 연결·오류·롤백 통합 검증 대기 |
| AC-005 | SQL 이름 바인딩→DB별 placeholder 변환, 문자열·주석 처리·삽입 문자열 테스트 |
| AC-006 | 서버 행 제한·스트리밍·바이트 제한·드라이버 시간 제한 구현. 실제 취소·시간 제한 동작 대기 |
| AC-007 | 변경 미리보기 롤백·미처리 오류 롤백 테스트. 실제 테이블·트리거 안전성 확인 대기 |
| AC-008 | 구조·타입·경로 참조·순환·트랜잭션·DB 프로젝트 범위·라우트 충돌 검사. 전체 JSON Schema 포함 관계 증명은 미구현 |
| AC-009 | 프로젝트 ZIP을 새 디렉터리·별도 Python 프로세스에서 실행, 실제 응답·인증·관리 API 부재 확인 |
| AC-010 | Flow revision·노드 ID·오류 코드·실행 ID·시간 기록, UI Trace 및 과거 메타데이터 조회 구현 |
| AC-011 | Secret 환경 변수 참조·입출력 원문 없는 추적·생성물 관리 코드 제외. 전체 보안 회귀 검사는 후속 |
| AC-012 | 고정 ZIP 시간·정렬·해시 manifest, 같은 입력·UI 변경에서 동일 ZIP 테스트 |
| AC-013 | 타입·null/미정의·정밀 숫자·참조·기본 분기·오류·트랜잭션 테스트. 실제 DB 오류·취소 적합성은 추가 필요 |

명시적 요청 취소는 실행 레지스트리와 드라이버 cancel을 사용한다. 클라이언트 연결 종료 감지·프로세스 간 취소 전파·운영용 영구 추적 수집기는 별도 보강이 필요하다. Docker 정의를 제공하지만 기동은 미검증이다.
