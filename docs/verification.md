검증 오류 수정: 일반 노드에 true/false 연결선이 있으면 포트 검사 단락 평가 때문에 연결 테이블 생성이 생략되어 KeyError가 발생하던 문제를 수정했다. 허용하지 않는 포트와 중복 포트는 명시적 검증 결과로 반환한다. XML 변환 → 구성 검증 → 오류 안내 → 경로 수정 → 재검증까지 실제 브라우저에서 확인했다. Python 테스트 35개와 브라우저 E2E 6개 통과.
