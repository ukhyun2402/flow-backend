# 구현 결정

2026-10-14 · 초기 구현

- Java 17 바이트코드, Spring Boot 3.5.16, Maven. 로컬 검증 JDK는 25.0.2, 컨테이너 기준 JDK 21. DB 드라이버별 JDK 지원은 실제 DB 통합 검증 후 확정한다.
- Flow JSON 1.0 및 JSON Schema Draft 2020-12. UI 위치는 실행 명세와 분리하며 생성물에서 제외한다.
- Spring MVC 기반 동기 실행. JDBC는 DB별 풀을 사용한다. 트랜잭션 연결은 실행 컨텍스트에서 소유한다.
- 생성 서버와 미리보기는 동일한 core/db/runtime 소스를 사용한다. ZIP은 정렬된 경로와 고정 시간으로 생성한다.
- 개발용 저장소는 원자적 파일 저장이다. PostgreSQL 저장소 전환, 다중 인스턴스 동시 수정은 후속 작업이다.
- 비밀정보는 환경 변수 참조로 해석한다. DB·외부 서비스 연결 설정은 운영자가 제공하는 외부 파일이다.
- 관리 API는 길이 24자 이상 환경 변수 토큰으로 admin/editor/runner 권한을 구분한다. 계정별 로그인·SSO는 아직 없다.
- 생성 API는 bearer 또는 public을 명시해야 한다. public은 Flow에 명시적으로 저장한 경우에만 허용한다.
- LOB 미리보기는 메모리 무제한 수집 방지를 위해 현재 차단한다. 문자열·정밀 숫자·일반 날짜 타입을 우선 지원한다.
- 변경 미리보기는 development/test 환경 및 rollbackSafetyVerified 확인을 모두 요구한다. 이 값은 DB 관리자가 트리거·테이블 엔진 등을 확인한 뒤 설정하는 운영상 확인이며, 프로그램이 부작용을 자동 판정했다는 의미가 아니다.
- SQL 파서는 허용 문장 종류 검증에 사용한다. SELECT 내부 함수 부작용까지 보장하지 않으므로 조회 미리보기 연결은 DB의 읽기 전용 계정을 사용한다.
