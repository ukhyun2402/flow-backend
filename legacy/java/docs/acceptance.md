# 기획서 수용 기준 추적

실행 가능한 초기 구현의 상태를 기록한다. `구현/로컬 검증`은 실 DB·컨테이너 환경 인증을 의미하지 않는다.

| 기준 | 상태 | 근거·남은 작업 |
|---|---|---|
| AC-001 | 부분 | 편집·불변 버전 저장·복원 구현, DB 없는 예제 미리보기·생성 서버 E2E 통과. SQL 조회 예제는 실 DB 필요 |
| AC-002 | 구현/로컬 검증 | UI 변경 시 생성 ZIP 동일성 자동 테스트 |
| AC-003 | 부분 | 종류별 형태·아이콘·텍스트 구현, 형태 정교화·접근성 추가 검증 필요 |
| AC-004 | 미검증 | Tibero·Oracle·MySQL 인스턴스·계정 및 Tibero JAR 필요 |
| AC-005 | 구현/로컬 검증 | Spring 이름 바인딩과 PreparedStatement, SQL 삽입 문자열 테스트 |
| AC-006 | 부분 | DB별 SQL 행 제한·드라이버 행 제한·문자열 스트리밍 한도·바이트 제한·query timeout 구현. DB별 취소·타임아웃 검증 필요 |
| AC-007 | 부분 | H2 롤백 테스트 통과. 실제 DB 테이블·트리거·엔진 안전성 확인 필요 |
| AC-008 | 부분 | 스키마·포트·도달·순환·경로별 참조·트랜잭션·기본 정적 타입 검사. 전체 JSON Schema 포함 관계·SQL 결과 타입 분석은 후속 |
| AC-009 | 구현/로컬 검증 | ZIP 독립 Maven 빌드, 별도 JVM API 응답, 인증, 관리 API 부재 확인 |
| AC-010 | 구현/로컬 검증 | Flow revision·nodeId·시간·오류 코드 추적과 캔버스 연결. 미리보기는 파일 보관, 생성 서버는 구조화 로그 출력. 영구 수집기는 별도 연동 |
| AC-011 | 부분 | 외부 Secret 참조, 생성물에 UI·미리보기 데이터 제외, 원문 없는 추적. 전체 보안 회귀 검증 추가 필요 |
| AC-012 | 구현/로컬 검증 | 동일 입력 ZIP 바이트 동일성·UI 독립성·파일 해시 manifest 테스트 |
| AC-013 | 부분 | 엄격한 타입·null/미정의 구별·기본 분기·오류 테스트. 전체 연산·DB 오류·취소 적합성 확대 필요 |

다음 검증에는 고객 환경별 DB 접속 정보와 Tibero JDBC 배포 조건이 필요하다. DB 접속 성공만으로 지원 완료 처리하지 않는다.
