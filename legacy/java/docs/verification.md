# 검증 기록

2026-10-14 · Windows · OpenJDK 25.0.2 · Maven 3.9.11

- Java 테스트 16개 통과, 실패·오류·건너뜀 0개: CoreTest 7, ExecutionTest 6, PlatformTest 3.
- 검사 내용: 스키마, 순환·경로 참조, 엄격한 타입, null/미정의, SQL 문장 제한, 바인딩, 조회 행·바이트 제한, H2 롤백, 미리보기/실제 커밋 차이, 단일 분기, 업무 오류 코드, 정밀 소수·큰 정수, HTTP 고정 origin·리다이렉트 차단, 불변 버전, 경로 이탈, 인증 없는 관리 API 차단, OpenAPI 경로 파라미터, 생성 ZIP 재현성·UI 독립성·관리 소스 제외.
- `npm.cmd --prefix frontend run build` 통과: TypeScript 검사 및 Vite 프로덕션 번들. SQL 편집기는 지연 로딩한다. Monaco 편집기 번들 크기 경고가 남아 있다.
- Maven 실행 JAR 패키징 통과.
- 별도 프로세스 수용 테스트 통과: 관리 API 검증·미리보기 → ZIP 생성 → 새 디렉터리에서 독립 Maven 빌드 → 생성 서버 기동 → 인증 없는 요청 401 → 인증 요청과 미리보기 응답 일치 → 관리 경로 404. 실행 후 테스트 프로세스를 종료한다.
- 브라우저 초기 렌더링과 노드 표시를 확인했다. 좁은 화면의 잘림을 발견해 반응형 패널로 수정했다. 이후 브라우저 세션 연결이 만료되어 최종 화면의 상호작용 재확인은 미완료이다.

실제 Tibero·Oracle·MySQL은 접속 환경이 없어 검증하지 않았다. JDBC 공통 동작은 H2에서 검사했으며 대상 DB의 동작을 대신 인증하지 않는다. Docker CLI가 없어 컨테이너 실행은 미검증이다. JDK 17/21 실제 기동 검증은 별도이며 현재 빌드 바이트코드 타깃은 Java 17이다.
